# Sistema Financeiro Desktop

Aplicação desktop desenvolvida em Java para gestão de contas e movimentações financeiras, com interface gráfica interativa e suporte a banco de dados relacional.

## Sobre o Projeto

O projeto consiste em um sistema completo de controle financeiro que permite cadastrar contas, registrar movimentações de entrada e saída, e consultar relatórios diretamente em uma interface visual. O código foi desenvolvido utilizando a arquitetura DAO (Data Access Object) para separar a lógica de negócio das operações de banco de dados, garantindo organização e manutenibilidade.

## Principais Funcionalidades

- Cadastro, alteração, remoção e listagem de contas financeiras.
- Registro detalhado de receitas e despesas.
- Interface gráfica desenvolvida com Swing e WindowBuilder.
- Persistência e manipulação de dados integradas ao PostgreSQL.

## Tecnologias Utilizadas

- **Linguagem:** Java
- **Interface Gráfica:** WindowBuilder / Swing
- **Banco de Dados:** PostgreSQL
- **Conectividade:** JDBC
- **Padrão de Arquitetura:** DAO (Data Access Object)
